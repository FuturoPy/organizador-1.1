✨ Assistente de IA

IA geral (padrão): cole em “Chave da API” a chave da Anthropic (sk-ant…), do Google Gemini (AIza… ou AQ.Ab…, grátis em aistudio.google.com/apikey), da OpenAI (sk-…) ou da Groq (gsk_…); o site reconhece o provedor pelo começo da chave. Em “Modelo”, para o Gemini use gemini-flash-latest. Conversa sobre qualquer assunto, escreve, traduz, programa, pesquisa na web e ainda edita o PDF e organiza o Drive. Precisa de uma chave da API (console.anthropic.com), cobrada por uso, separada de qualquer assinatura do Claude. A chave fica só neste navegador. Para sites com visitantes, use um proxy (URL + senha abaixo) e deixe a chave só no servidor. Local: roda no navegador, sem chave e sem custo, mas só entende comandos de PDF, Drive e projetos (digite "ajuda" no chat).

Configurações

O Google exige um Client ID gratuito (uma vez só). 1. console.cloud.google.com → criar projeto. 2. Ativar a Google Drive API (APIs e serviços → Biblioteca). 3. Tela de permissão OAuth → Externo; em Acesso a dados, adicione só o escopo …/auth/drive.file e clique em Publicar app. 4. Credenciais → ID do cliente OAuth → Aplicativo da Web → em “Origens JavaScript autorizadas” coloque o endereço deste site (e http://localhost). 5. Cole o Client ID abaixo. Opcional: para escolher PDFs e pastas do Drive, ative também a Google Picker API, crie uma Chave de API e cole-a junto com o Número do projeto; sem eles os botões “Escolher” ficam escondidos e o resto funciona normalmente.
